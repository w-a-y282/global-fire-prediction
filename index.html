About

How to Use

  • Map – Browse historical fire data with date picker.
  • Forecast – Select a base date and offset to view model predictions for future dates.
  • Statistics – Aggregated metrics for dates you have viewed.
  • Model – View configuration and average performance.

Data & Model

This system visualises fire predictions from the zhurong foundation model. Data is aggregated from multiple regions and presented with a spatial matching algorithm (5 km radius). The dashboard allows interactive exploration of daily fire occurrences and model performance.
